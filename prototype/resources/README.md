# 游戏配置

编辑 `game-config.js` 后刷新页面生效，无需构建。配置使用可注释的 JS 数据对象，兼容直接打开 `index.html`。

## 建筑 buildings

每个键是建筑 ID，建造菜单自动读取所有条目。复用现有机制和 sprite 时，可以通过添加条目扩展建筑。

| 字段 | 含义 |
| --- | --- |
| name / desc / icon / color | 名称、说明、后备图标、效果颜色 |
| kind | tower 炮塔、wall 道路障碍、miner 采矿机 |
| sprite | 图集名称，可复用 gun/cannon/slow/miner/wall |
| buildCooldown | 同类建筑成功放置后的冷却秒数，与攻击冷却独立 |
| levels | 各级数据，数组长度决定等级上限 |
| levels[].cost | 本级总魔力占用；升级追加值为下一级减当前级 |
| levels[].hp | 本级生命上限，目前仅障碍受攻击 |
| levels[].damage / cool / range | 直接伤害、攻击间隔秒数、射程格数 |
| levels[].splashDamage | 对溅射范围内其他敌人的伤害，主目标不重复受伤 |
| attack / blastSize | single 或 splash；正方形溅射范围边长，当前 3 格 |
| slowFactor / slowDuration | 剩余移速倍率、持续秒数；重复命中刷新时间，不叠加 |
| turnSpeed | 弧度/秒的炮口转速 |
| coverage | 方形采矿半径，2 表示 5×5 格 |
| healOnUpgrade | 升级是否回满生命 |

| 建筑 | 建造 | 升二级追加 | 升三级追加 | 建造 CD |
| --- | ---: | ---: | ---: | ---: |
| 普通炮塔 | 25 | 20 | 30 | 5 秒 |
| 减速塔 | 35 | 25 | 35 | 10 秒 |
| 爆破塔 | 55 | 35 | 55 | 5 秒 |
| 障碍 | 15 | 10 | 20 | 20 秒 |
| 采矿机 | 免费 | — | — | 5 秒 |

三个攻击塔间隔均为 1 秒。普通炮塔每发伤害各级均为 60，每次分别发射 1/2/4 发，减速塔 12/24/36，爆破塔直击 120/240/360、溅射 30/60/90；减速强度和持续时间保持不变。其余攻击伤害、生命、射程等以 levels 内数值为准。升级不触发建造 CD，拆除不会清除 CD。

## 敌人 enemies

`hp` 为固定生命，不随波次增长；`speed` 为固定格/秒；`wallDps` 为啃食障碍秒伤；`baseDamage` 为漏怪伤害。`sprite / spriteSize / radius / color / highlight / mouth` 控制图集及后备绘制。

普通生命 200、啃食 DPS 100；重甲生命 570、啃食 DPS 25。两者速度均为 1.15 格/秒，无护甲或减伤。新敌人需要在 batches 中引用其 ID 才会生成。

## 关卡 rules

- `baseHealth`：基地生命。
- `manaPerOre`：每台采矿机对每块矿石的容量贡献，当前 6；单块最多贡献 30 点。
- `maxMinersPerOre`：每块矿石最多计入的采矿机数量，当前 5；拆除会移除相应贡献。
- `initialDelay`：开局准备秒数，当前 20；`showCountdown` 控制是否显示。
- `spawnInterval`：同批逐个出怪间隔，当前 0.65 秒。
- `batches`：有顺序的小批次，当前共 48 个敌人。`enemies` 是敌人 ID 到数量的映射，按书写顺序逐个生成。
- `batches[].trigger.kills`：本批击杀达到此数量后可启动下一批。
- `batches[].trigger.progress`：本批任意敌人最远推进比例达到该值也可启动下一批，0.6 表示 60%。
- 每批全部生成后判断推进条件；击杀或推进任意满足即可，不要求清场。清场也可直接推进，无固定等待。
- `batches[].assault:true` 标记一次总攻；当前只在最后一批设置，18 个普通敌人后接 2 个重甲。前面普通批次不计作总攻。
- 最后一批全部生成且场上无存活敌人后判胜；基地生命归零优先判负。

## 地图 map-level-1.js

地图独立于数值配置，通过 `MAP_CONFIG` 提供数据，页面在游戏逻辑前加载此文件。修改后刷新生效。

| 字段 | 含义 |
| --- | --- |
| width / height | 地图列数和行数，当前 28×18 格 |
| cellSize | 每格像素边长，当前 66 |
| allowedBuildings | 可建造建筑 ID 列表，同时决定菜单顺序；第一关为 gun、miner，省略时开放全部 |
| paths | 路径拐点数组；每个点为 [列,行]，坐标从 0 开始 |
| oreClusters | 矿区数组；每个矿区含多块矿石坐标 |

相邻路径拐点须水平或垂直连接，游戏自动展开为逐格路线。路径首点为出怪点，末点为基地。矿石不得位于道路或地图外，且不应有重复坐标。

当前地图保持单一出怪点、53 格行走路径、5 处矿区共 15 块矿石。总尺寸 1848×1188 像素，镜头自动限制最小缩放以铺满屏幕。

关卡建筑限制同时作用于菜单和建造校验。第一关仅开放普通炮塔与采矿机，其他建筑数值仍保留在 game-config.js，后续关卡可通过 allowedBuildings 开放。

### 普通炮塔分级外观与齐射

`levels[].projectiles` 控制同次发射的弹数，当前 1/2/4；每发沿炮管方向直线飞行，仅命中沿途第一个敌人时结算 `damage`。`cool` 各级均为 1 秒，`damage` 均为 60。`muzzleForward / muzzleOffsets` 是以格为单位、随上层旋转的炮口前向与横向偏移。`head.src` 可为本级指定独立上层图片，`head.frame` 为可选的归一化裁切矩形 [x,y,width,height]，`head.pivot` 是裁切区域内的归一化旋转中心；不提供 head 时沿用 sprite 指定的原图集上层。一级单管，二级保留原双管，三级四管。

### 弹丸与碰撞

`rules.projectileSpeed` 为弹丸速度（当前 14 格/秒），`projectileRadius` 为弹丸碰撞半径（当前 0.035 格），建筑可用同名字段覆盖。炮口同向平行发射，不追踪也不汇聚；逐帧对飞行线段和敌人圆形碰撞体求最早碰撞，未命中一直飞到地图边界。普通攻击命中后移除；爆破与减速效果同样在实体弹丸实际命中时触发。

### 地形材质 terrain

地图配置中 `terrain.grass / terrain.path` 分别定义草地与路径；`src` 是相对原型页面的图片路径，`tileCells` 是一张图片铺设的边长格数，当前草地 4 格、路径 3 格。图片载入后自动重建缓存地形；未加载时使用纯色后备。地形外观不影响路径坐标、碰撞或建筑格子。

### 草地变体与出怪标记

`terrain` 可继续登记 clover、tufts、flowers 等地形图片；`grassVariants` 按名称引用可混合的草地类型。草地底纹通过镜像获得相同边界，变体通过边缘透明遮罩过渡到共同底色，可互相衔接；随机旋转由固定坐标噪声决定，画面不会每帧变化。`spawnMarker.src / sizeCells` 设置出怪旗图片和以格为单位的绘制大小，只有视觉效果，不影响出怪坐标。

### 绘制式 UI 素材

`ui-skins.css` 加载 assets/ui-hud-panel-v1.png、ui-controls-v1.png 及 ui-build-menu-2/3/4-v1.png。菜单由 allowedBuildings 数量选用对应独立 PNG，第一关两项使用二选项模板。按钮图集由左到右为暂停、继续、重新开始，通过 aria-pressed 切换暂停/继续帧。文字与交互区域叠在图像上，数值仍实时更新。当前支持 2—4 项固定模板；更多选项暂沿用四项底板并滚动，后续可继续增加对应素材。
